## Ghi chú về git

`.gitignore` ở gốc repo có dòng `*.py` (mục "LOCAL TOOL BINARIES"), nên mọi tệp Python của agent bị git bỏ qua. Đây là lý do v1 chưa từng được commit. Kế hoạch này không đổi chính sách đó; muốn đưa code v2 vào git cần chủ dự án quyết định (ví dụ thêm `!backend/agents/testspec-agent/**/*.py` vào `.gitignore` gốc, hoặc `git add -f`). Lint dùng `respect-gitignore = false` để vẫn kiểm được mã.
