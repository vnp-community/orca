# Notes service: User Requirements (URD) v1.0

## 1. Introduction

### 1.1. Purpose

The Notes service lets a client store and read short notes over HTTP.

## 2. Functional requirements

| Mã FR | Yêu cầu | Ưu tiên |
| --- | --- | --- |
| FR-NOTE-01 | The service shall store a note sent by a client. | M |
| FR-NOTE-02 | The service shall return the notes it stored. | M |
| FR-NOTE-03 | The service should report whether it is running. | S |
